# adelka4745 Toolkit

Это приложение на **HTML/CSS/JS**, упакованное как **MSIX/APPX** для Windows.

## Структура

```
.
├── index.html
├── style.css
├── script.js
├── AppxManifest.xml
├── Package.appxmanifest
└── README.md
```

## Установка

### Через PowerShell

```powershell
Add-AppxPackage -Path .\adelka4745-Toolkit.msix
```
